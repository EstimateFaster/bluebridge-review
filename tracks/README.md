# 招新评测 · 题目与提交规则

本目录存放蓝桥工作室招新评测的公开题面与候选人提交。

## 当前批次

本轮只评测 **Vela 快应用** 方向（Android 方向暂缓，后续开放）。

| 题号 | 题目 | 考察重点 | 难度 |
|---|---|---|---|
| [题 1](vela/task-1-weather/) | 一屏挑战：手环天气单页排版 | UI 设计、信息层级、小屏适配 | ★★ |
| [题 2](vela/task-2-restyle/) | 改版题：静态壳 + 三块新功能 | 自绘键盘、功能设计、UI、改版维护 | ★★★ |
| [题 3](vela/task-3-whack-a-mole/) | 完整 rpk：打地鼠小游戏 | 完整开发、多页路由、玩法与反馈 | ★★★ |

> 三位候选人不一定三题都做：UI 特长生优先题 1；有改版/维护经验优先题 2；完整工程能力优先题 3。具体以评审方通知为准。

## 通用规则（所有题适用）

1. **允许并鼓励 vibecoding**：可以使用任何 AI 工具，但需要能读懂、能修改、能讲清楚自己的作品；
2. **提交内容**：源码目录、构建出的 `.rpk`（或构建说明）、3–5 张运行截图、`README.md`（怎么跑 + 设计说明 + AI 使用说明 + 迭代日志）；
3. **提交位置**：`submissions/<github-id>-<task>/`，例如 `submissions/example-task1/`；
4. **现场环节**：
   - 演示 + 讲解思路；
   - **现场改动**（评审方临时加一个小需求或改一个限制）；
   - 追问（实现细节、取舍、AI 用法）；
5. **P0 必过项**：能跑起来 + 能讲清楚 + 现场改得动。缺任意一项视为未通过；
6. 题面会按批次轮换，已发布题面不保证长期有效。
